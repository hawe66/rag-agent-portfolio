# Week 9 Retrospective — Cross-modal RAG MVP (1차 붕괴 → 재작업 완료)

> 상세 평가·수치: `docs/week9_evaluation.md`(유일한 유효 결과). 결함·재검토: `docs/WEEK9_DEFECTS.md`, `docs/WEEK9_REWORK_PLAN.md`. 명세: `docs/WEEK9_TASKS.md`.
> 본 문서는 주차 레벨 회고(무엇을 목표했고, 무슨 일이 있었고, 무엇을 배웠나)다. 숫자의 근거는 위 평가 문서를 본다.

## 1. 목표

멀티모달 RAG MVP. 도면에만 있는 정보(부품 위치 / 끼움·회전 방향 / 제어판 아이콘)를 답하는지를, **text-only baseline(ADR-011 앵커: model 50% / page 25%) 대비 C0 / C1(캡션→텍스트 RAG) / C2(CLIP)** 비교로 측정. 가설: "세부를 읽고 추론해야 하는 도면 질문에는 VLM이 필요하다"를 데이터로 공정하게 검증.

## 2. 무슨 일이 있었나 — 1차 붕괴와 메타 교훈

1차(2026-06-30)는 rasterize·캡션 252건·CLIP 인덱스·비교 하네스를 다 만들고 결론("캡션 무용", "CLIP OOD")까지 보고했다. 그러나 **하네스가 측정하려는 것을 실제로 측정하는지 검증하지 않았다.** 재검토에서 결함 D1~D7·E1~E9가 드러났고, 그 결론들은 대부분 **실험 설계 결함의 그림자**였다. 1차 결과는 전량 폐기.

메타 교훈(§5.3 원칙과 정합): **저울을 먼저 검증하라.** 검색 구조가 고장난 상태에서는 캡션 품질이 시험조차 되지 않는다 — 고장난 저울로 잰 무게는 아무리 정밀히 읽어도 무의미하다. 이 인식이 이번 주의 실질 산출물이다.

## 3. 재작업 — 무엇을 고쳤나

- **A1 검색 재설계(`src/mm_retrieval.py`):** 텍스트 top-3 + 페이지 키 co-retrieval + 캡션 레인 top-2(전체 예산 5 유지). 1차의 "텍스트+캡션 단일 풀 top-k에서 캡션이 밀림"을 정면 제거.
- **A2 캡션 품질:** v2 프롬프트(있는 것만·콜아웃 라벨 원문 전사·모양 묘사, 슬롯 강제 제거), 95→150dpi, 모델 **gpt-4o-mini→gpt-4o**(파일럿 p18 콜아웃 9/9·환각 0). 비용 정정: mini의 이미지 과금이 4o의 ~34배 → 전량 재캡션도 $3~5.
- **신뢰 토대 B1~B4:** 레이어 분리·앵커 재현 / 대조군 재구축(순수 text-only 6) / CLIP sanity(버그 아님 확정) / judge 분리·엄격화 + 수동채점 병행 + IR8 라벨 audit.

## 4. 결과 — 층별 요약

| 층 | 핵심 수치 |
|---|---|
| 신뢰 토대 | **C0 citation = ADR-011 앵커 정확 재현(model 50% / page 25%)** → 하네스가 기준선과 같은 언어로 말함 |
| Retrieval | caption-hit **2/8 → 6/8**; 캡션-only 검색 **75%** vs CLIP **12%**(sanity 3종으로 버그 기각 → 도메인 부적합) |
| Answer(수동채점) | IR8 **C1 2/8 vs C0 1/8**; 대조 **C1 4/6 vs C0 3/6**(캡션에 의한 희석 없음) |
| Judge 캘리브레이션 | 엄격 judge = 일관된 하한. 불일치 7건 **전원 false negative**(대부분 골든셋 GT 결함) → v3 필요 |

## 5. 이번 주의 한 문장 — IR-W1

정수기 왼쪽 자리(①=**중금속9 흡착 필터**)의 정보는 본문에 없고 도면에만 있다. **C0는 정직하게 거절, C1은 gpt-4o 캡션이 운반한 그 정보로 정답.** cross-modal 패턴의 **첫 실증**이다. 단 **n=1** — 방향 증거이지 결론이 아니다.

## 6. 잔여 병목과 원인 (정직 기록)

실패 6/8의 지배 원인은 **검색이 아니라 캡션 내용**이다. 전체 페이지 캡션은 150dpi·gpt-4o로도 **아이콘 모양·부품의 공간 위치·회전 방향**을 담지 못한다(§week9_evaluation §3·§4). v2의 "라벨 원문 전사" 원칙이 v1의 공간 위치 서술(상/하/좌/우)을 밀어낸 트레이드오프도 여기 겹친다.

→ **10주차 방향: bbox/영역 crop 캡션(영역 단위 위치·라벨·모양을 구조화 JSON으로).** "VLM이 필요하다"는 "**영역 단위로** VLM을 써야 한다"로 정밀화됨.

부산물: 엄격 judge가 **대조군 GT 결함**(모호·모델 미특정·매뉴얼과 모순)을 다수 노출 → golden set v3 정비 필요.

## 7. 운영 교훈

16GB 호스트에서 단일 프로세스(reranker + 스토어 2개 + BM25 레인 2개)가 **2회 무징후 kill**(메모리 압박 / 야간 절전). 대응: **설정군별 프로세스 분리 + 문항 단위 jsonl 체크포인트(죽어도 최대 1문항 손실) + caffeinate.** 실험을 끝까지 돌리는 것도 엔지니어링이다.
